# M001 禁令清单 + 正反示范

| 项目 | 内容 |
|---|---|
| 层 | prompt |
| 门槛 | 网页对话 |
| 状态 | 已验证（负面结果） |

## 做法

在提示词里逐条列出禁止的写法（禁用词、禁用动作、禁止升华），再给一个“错误示范”和一个“正确示范”。

这是最常见的去 AI 腔做法，网上大多数“写作提示词”都是这种结构。

## 已知问题

- 列出的禁用词本身进入了上下文，反而更容易被写出来。
- 禁掉一类毛病，模型会滑向另一类（见 [E001](../experiments/fiction/E001-rule-list.md) 的轮换顺序）。
- “正确示范”如果由模型生成，常常自己就违反了清单。
- 规则越长，越容易出现把规则写进正文的解说腔（F10）。
