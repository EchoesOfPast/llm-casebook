# 方法

“方法”是让模型输出想要效果的任何手段，不限于提示词。每个方法一个文件，按 `M编号-简短描述.md` 命名，用 [模板](../templates/method.md) 填写。

## 分层

| 层 | 说明 | 例子 | 门槛 |
|---|---|---|---|
| `prompt` | 单条提示词怎么写 | 角色设定、约束、文体伪装 | 网页对话 |
| `context` | 往上下文里放什么 | 作者认可的样本、资料、风格锚点 | 网页对话 |
| `workflow` | 拆成多步做 | 先列节拍再写、写完按清单改 | 网页对话 |
| `tooling` | 提示词加脚本或技能包 | 检查脚本、Claude Code skill | 本地工具 |
| `decoding` | 采样参数 | 温度、Min-P、Logit Bias | API |
| `model` | 换模型或换模式 | Base 模型续写、不同厂商对比 | 视模型而定 |
| `training` | 改权重 | 少量数据 SFT、LoRA | 显卡 |

一个方法可以跨多层，例如“样本 + 两步工作流”。

## 状态

- **待验证**：有思路，还没有实验记录。
- **已验证**：至少一个情境下有规范实验（≥3 次原始输出），并写明结果。
- **已失效**：曾经有效，在新版本模型上复测不再成立。保留，不删除。
