# M002 作者认可文本作锚点

| 项目 | 内容 |
|---|---|
| 层 | context |
| 门槛 | 网页对话 |
| 状态 | 待验证 |

## 假设

模型模仿具体文本的能力，强于理解抽象规则。与其写“不要煽情、不要死细节”，不如只放一两段作者本人写的、或作者明确认可的文本，让模型对齐它的句长、密度和留白。

和 M001 的区别：

- 不写禁用词清单，避免把禁用词带进上下文。
- 锚点必须来自作者，不能用模型自己生成的“示范”。
- 在全新对话里使用，不接在长对话后面。

## 做法

```
下面是我写的一段小说，请保持完全相同的写法续写。

【样本】
（作者认可的 1–2 段，每段 100–200 字）

【前文】
（要续写的上文）

【续写】
```

## 待测问题

- 样本数量：1 段和 3 段有没有差别？
- 样本和前文题材不同时，会不会发生场景漂移（F15）？
- 加一句极短约束（如字数上限）是否更好？
