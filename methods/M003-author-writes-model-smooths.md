# M003 作者写内容，模型只顺句子

| 项目 | 内容 |
|---|---|
| 层 | workflow |
| 门槛 | 网页对话 |
| 状态 | 待验证（有一次正面记录） |

## 假设

模型擅自补的细节，往往是全文最弱的地方：要么通用（F18），要么和作者设定不符。让作者提供人物和场景，模型只负责语言和结构，可以避开这一类问题。

## 做法

1. 模型先指出原稿的问题，并给出轻改和收紧两个版本，不替作者补设定。
2. 遇到需要具体内容的地方（地点、回忆细节），留空让作者填，或者明确标注“以下是我编的”。
3. 作者用自己的话重写内容。
4. 模型只整理：标点、衔接、句子结构，并逐条说明改了什么。
5. 作者逐句挑问题（作用是什么、是否流水账、是否多余），模型按意见改，必要时调整结构，不在原结构上堆修饰。

## 已知问题

- 第 4 步模型仍会忍不住加细节（见 E002 第 4 版），需要作者把关。
- 作者说“你填一下吧”时，模型编的内容可以当作启发，最终仍要作者换成自己的。
- 依赖作者的判断力；作者不挑问题时，效果接近普通润色。
