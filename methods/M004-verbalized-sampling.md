# M004 一次要多个候选并标概率（Verbalized Sampling）

| 项目 | 内容 |
|---|---|
| 层 | prompt |
| 门槛 | 网页对话 |
| 状态 | 待验证（英文研究有证据，中文小说未测） |
| 来源 | Zhang et al. (2025). [Verbalized Sampling: How to Mitigate Mode Collapse and Unlock LLM Diversity](https://arxiv.org/abs/2510.01171) |

## 假设

模型输出千篇一律，一个重要原因是训练数据中的“典型性偏好”：人类标注者天然偏好熟悉的文本。只要一个答案，模型就给出最典型的那个；要它给出多个候选并标上概率，它会更接近预训练时学到的、更丰富的分布。

对小说来说，最典型的续写往往就是套话。如果能让模型给出不那么典型的候选，就有机会避开套话。

## 研究结果（英文）

- 写诗、写故事、讲笑话等创意任务中，语义多样性比直接提问提高约 1.6–2.1 倍。
- 人类评分（1–4 分，评多样性）：故事从 2.74 提高到 3.06，诗从 1.90 提高到 2.39。
- 可以在提示词里加概率阈值来调节多样性，阈值越低越多样。

**局限：**
- 提高的是**多样性**，不等于质量。论文的质量分数由模型（Claude 3.7 Sonnet）评判，不是人。
- 小模型用基础版时质量会下降；加“先逐步思考”（VS-CoT）或多轮追加（VS-Multi）在大模型上能保持质量。
- 每次要的候选不宜太多，论文用的是 5 个。

## 做法

**直接提问（对照组）**

```
请续写下面这段文字，150–300 字。

【原文】
（S001 测试输入）
```

**VS-标准版**

```
请为下面这段文字写 5 个不同的续写版本，每个 150–300 字。
为每个版本标注一个概率（0 到 1 之间），表示在你所有可能的续写里，这个版本出现的可能性有多大。

【原文】
（S001 测试输入）
```

**VS-低概率版**（只要不典型的候选）

```
请为下面这段文字写 5 个不同的续写版本，每个 150–300 字。
为每个版本标注一个概率（0 到 1 之间），表示在你所有可能的续写里，这个版本出现的可能性有多大。
只给出概率低于 0.10 的版本。

【原文】
（S001 测试输入）
```

**VS-思考版**：在标准版开头加一句“先逐步想一想这段文字接下来可能怎么发展，再写。”

## 在 S001 上的测试设计

1. 每种提示各在**全新对话**中跑 3 次。直接提问每次 1 段，共 3 段；每种 VS 版本每次 5 段，共 15 段。
2. 去掉概率标注和来源，打乱顺序，交给作者盲评。
3. 作者对每段标：能用 / 改改能用 / 不能用，并标出命中的失败模式编号。
4. 比较各组：
   - “能用”的比例；
   - 平均每段命中的失败模式数，特别是 F03 套话、F06 死细节、F15 场景漂移；
   - 同组内各段之间是否雷同（作者主观判断即可）。
5. 记录模型、版本、日期，写成实验记录。

**要回答的问题：**低概率候选是更少套话，还是只是更怪？“多样”能不能转化成“能用”？
