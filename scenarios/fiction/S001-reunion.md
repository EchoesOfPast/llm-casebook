# S001 重逢场景：不煽情、不摆拍

| 项目 | 内容 |
|---|---|
| 领域 | 小说 / 中文 / 现实题材 |
| 想要的效果 | 情绪冲击场景写得克制、真实，没有 AI 腔 |
| 评判方式 | 人工盲评，对照 [失败模式清单](failure-modes.md) |
| 口味说明 | 偏好现实主义的克制写法。网文爽感、强情绪外放不在这个情境的目标里，可另开情境 |
| 状态 | 开放：欢迎提交方法和实验 |

## 测试输入（作者原文）

> “秦……妙妙？”
>
> 我没想到，会在这种地方再见到她。
>
> 那一瞬间，以前的日子一下子全涌了上来。爸爸每天骑着自行车送我上学、接我放学。一放学，我就和邻居家的胖虎、苏糖，还有秦妙妙，凑到老槐树底下跳皮筋、弹玻璃珠、吃雪糕。刘阿姨、刘老头、张管家进进出出，总要念叨我们几句。一直玩到妈妈站在楼道口喊我回家吃饭，喊了好几遍，我才肯走。
>
> 这些画面一幕一幕浮现在眼前，仿佛就在昨天。一眨眼，竟然已经过去十三年了！
>
> 秦妙妙看着我：“王喵喵，这么多年没见，你居然还能一眼认出我？”
>
> 她话还没说完，我的眼泪就下来了。

## 任务

从“我的眼泪就下来了”之后续写，150–300 字。

## 硬性事实（违反即判 F16）

- 秦妙妙已经认出并叫出了“王喵喵”，语气带点打趣。
- “我”当场落泪。
- 两人十三年未见，小时候是邻居、玩伴，一起玩的还有胖虎、苏糖。
- 地点未指定，不要自行补成家中、玄关等私人空间。

## 重点检查

F04 舞台腔、F06/F07 死细节与摆拍、F10 解说、F12 视角穿帮、F15 场景漂移、F16 篡改前文。
